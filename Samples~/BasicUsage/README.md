# Core 기본 예제

`CoreCollectionsSample.unity` Scene에 `CoreCollectionsSample` 컴포넌트가 이미 부착된 GameObject가
포함돼 있습니다.

## 확인 절차

1. `CoreCollectionsSample.unity`를 엽니다.
2. `Core Collections Sample` GameObject를 선택하고 Inspector 컨텍스트 메뉴에서
   `Deque 예제 실행`을 실행합니다.
3. Console에 `Deque<T>`의 양방향 삽입·제거 결과 로그(`first / last`)가 출력되는지 확인합니다.
